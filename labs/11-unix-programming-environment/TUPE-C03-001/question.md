# TUPE-C03-001 — Pipeline Report Builder

Two commands are available in your Linux environment:
```bash
tupe-source-a
tupe-source-b
```
Each command writes a mixture of informational, warning, and error records to standard output.

Write a Bash script named pipeline_report.sh that accepts exactly one positional argument:
`pipeline_report.sh OUTPUT_FILE`

Your script must:
- Run both tupe-source-a and tupe-source-b.
- Process the output produced by both commands as one combined stream.
- Keep only records whose lines begin exactly with: `ERROR`
- Sort the retained records in ascending lexicographic order.
- Remove duplicate records.
- Write the final report to OUTPUT_FILE.
- Replace any previous contents of OUTPUT_FILE; do not append to stale output.
- Exit successfully when the report is created.
- Produce the same correct report when run again with the same output path.

The source commands and their data are generated by the grading environment. Do not hard-code expected report records.

Your solution is graded by its observable behavior. Equivalent Unix shell implementations are accepted.

You may create and edit the script entirely from the terminal using an editor such as vi, vim, or nano.
